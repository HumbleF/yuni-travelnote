# 旅行攻略 Markdown 模板

> 设计哲学：**信息密度第一，可执行性第二，文采靠边站**。每个数字都要可验证（具体到分钟 / 元），每条建议都要可操作（具体到 App / 公众号 / 出口 / 门牌）。模板里的 `<!-- 注释 -->` 是写攻略时给自己的硬约束，正式发布前删掉即可（HTML 注释不会渲染到页面）。
>
> 文风：**客观信息**（价格 / 地址 / 时间 / 用时）走中性表格化；**提示 / 避雷 / 真心话** 用第一人称口语化，让人感觉是"刚去过的朋友写的"，不是百度百科。

> 配套规则在主仓 [README.md](../README.md)：
> - [内容质量红线](../README.md#内容质量红线写攻略前必读)（禁词词典 / 强制具体化 / 第一人称真心话）
> - [图片处理](../README.md#图片处理必读--写新攻略前看这一节)（自托管 / 命名 / 取图流程 / 三重验证）
> - [自查清单](../README.md#自查清单提交前跑)（提交前必跑的 ripgrep 命令）

## 一句话点评

- **适合谁**：喜欢历史人文 / 慢节奏 / 出片城市感的人；情侣、独旅、亲友团都合适

## 行程建议（4 天 3 夜·关西机场抵达）

| Day | 主题 | 行程要点 |
| --- | --- | --- |
| Day 1（傍晚） | 抵达 + 锦市场 | 关西机场 → HARUKA 75 min → 入住河原町 → **锦市场** 边走边吃章鱼烧、烤鳗 → **先斗町** 居酒屋晚餐 |
| Day 2 | 东山经典线 | 8:30 **清水寺**（避开 10 点后的旅游团）→ 二年坂三年坂 → 午餐"日东堂"抹茶 → **八坂神社 → 圆山公园** → 黄昏 **八坂塔**（拍照神位）→ 祇园四条 |
| Day 3 | 岚山 + 金阁寺 | 8:00 嵯峨野小火车（春秋限定）→ **竹林之道** → 渡月桥 → 午餐 "% Arabica" 河岸店 → 巴士 **金阁寺**（停留 40 min 足矣）→ 返河原町 |
| Day 4（返程） | 伏见稻荷 + 启程 | 7:00 **伏见稻荷大社**（必须早起，10 点后人挤到拍不出空镜）→ 京都站 拉面小路 午餐 → HARUKA 关西机场 |

> 节奏建议：每天上午 + 下午各一个景点，傍晚河原町 / 先斗町漫步喝酒。**4 天看 8 个景点已是上限**，再多就是赶路。

## 出片机位（按出片难度由易到难）

1. **八坂塔下坡** — 二年坂顶端，往下俯拍，**17:00-17:30 黄昏**，竖构图把塔放右下 1/3
2. **白川南通的小桥** — 祇园四条站 9 号出口走 4 min，**晚上 19:30 后**店家亮灯，水面倒影绝佳
3. **岚山渡月桥北岸** — **早上 7:30** 雾气未散，桥+山+秋叶（11 月）三件套
4. **伏见稻荷"奥社奉拜所"以上** — **早 7:00 前** 鸟居中能拍到完全没人的空镜
5. **锦市场入口（寺町通侧）** — 屋顶彩色木牌+灯笼，**任何时段** 抬头拍

## 打包清单

**必带**：护照 + 1 张 Visa 信用卡 + 5 万日元现金 + 充电器（A 型转换头）+ 雨伞（11 月多骤雨）

**别带**：大行李箱（京都酒店多在小巷，拉箱不方便；建议主行李寄关西机场，带 20L 背包入京都）

## 避雷集合（我自己踩过的坑）

- **不要在京都塔登顶** — 1,000 JPY 看一片低矮民宅，不如去清水寺木台
- **不要红叶季周末白天去永观堂** — 1.5 小时排队进去 20 min 看完，去真如堂同款红叶不排队
- **金阁寺不要待超过 40 min** — 没什么可走的，照片拍完就该上巴士去下一站
- **不要在花见小路追着艺伎拍照** — 已经被禁了，违规会被罚款 1 万日元，远远拍即可
- **不要图便宜买 4,000 JPY 以下的"和服体验"** — 化纤面料、配色塑料感，照片拍出来很出戏；选 6,000 JPY 以上的真丝套餐
- **不要相信"一日看三神社"的攻略** — 京都神社走完一座要 1.5h，三座等于一天都在赶路
