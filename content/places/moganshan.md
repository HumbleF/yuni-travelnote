## 一句话点评

- **适合谁**：想用一个周末从杭州 / 上海 / 苏州出逃去山里的人；情侣、亲子、闺蜜、独旅都合适
- **不适合谁**：想要奇险山岳风光（请去黄山）/ 极致刺激户外（请去神农架）/ 古镇水乡（请去乌镇 / 西塘 / 绍兴）/ 大型寺庙朝拜（请去普陀山）
- **最大亮点**：**5-6 月清晨竹海** + **裸心系 / 大乐之野级民宿的山景无边泳池** + **海拔 700 米无光污染的星空**，三件套叠在一起，江浙沪 3 小时圈内很难复刻
- **最大避雷**：**周末民宿涨价 50-100%**（平日 ¥800 周末 ¥1500 是常态）；**山顶老别墅景区** 80 元门票其实只看几栋远观式民国房子，30 分钟走完会觉得"门票踩雷"；**七八月暑假** 山下 35°C+ 时山上还有 28°C，但民宿价格再翻倍且一房难求

## 关于莫干山

莫干山位于浙江湖州德清县西部，海拔 700-720 米，距杭州西北 60 km、上海西南 200 km、苏州 130 km。19 世纪末由英国传教士开发为避暑地，民国时期蒋介石、宋美龄、毛泽东都在此小住，留下 200 多栋老别墅。2007 年南非人 High Latimer（高天成）建"裸心谷"，开启了中国精品民宿元年；现在山上山下分布着 800+ 家民宿，被称作中国民宿业的"硅谷"。

| 项目 | 信息 |
| --- | --- |
| 货币 | 人民币 (CNY) |
| 海拔 | 山顶约 720 m，山下镇区约 50 m |
| 气候 | 山顶比山下低 5-7°C；夏季山顶 22-28°C，冬季 0-8°C；雨量充沛，年雾日 200+ |
| 通讯 | 三大运营商山上 4G/5G 全覆盖，移动信号最稳；裸心谷以西部分山涧有盲区 |
| 抵达 | 高铁直达"莫干山站"或"德清站"（均在德清县城）→ 25 km 上山，无机场（最近萧山机场约 95 km） |
| 应急电话 | 110 / 120 / 119 / 山林防火 12119 |

> 山上和山下是两个世界：**山下莫干山镇 + 庾村** 是文创咖啡 + 老车站氛围；**海拔 700 米的别墅区 + 周边自然村**（后坞乡 / 三桥乡 / 庙前）才是民宿主战场。规划行程时一定要分清楚自己要哪种感觉。

| Day | 主题 | 行程要点 |

| Day 2（周日） | 早起竹海 + 老别墅 + 返杭 | **6:30 起 武陵竹海** 拍空镜 → 8:30 早餐回民宿 → 10:00 退房 → **莫干山风景区**（剑池 + 旭光台 + 主席下榻处，2 h 走完）→ 镇上午餐 → 15:00 滴滴下山 → 16:30 高铁返杭 |

### 3 天 2 夜（含徒步 + 骑行加长版）

| Day | 主题 | 行程要点 |
| --- | --- | --- |
| Day 1 | 抵达 + 庾村 + 山下慢悠 | 高铁 → 庾村 1932 午餐 → 入住山上民宿 → 民宿设施（泳池 / SPA / 围炉）→ 晚餐民宿 |
| Day 2 | 整日山上 | 6:30 武陵竹海 → 早餐 → 9:00 **后坞乡 → 屋脊头水库环线 骑行** 18 km / 2.5 h → 农家午餐 → 下午 **塔山徒步**（往返 3 km / 1.5 h，山顶看日落）→ 晚餐回民宿 → **22:00 露台看星空** |
| Day 3 | 老别墅 + 返程 | 早餐 → **莫干山风景区** 老别墅 + 剑池 → 镇上午餐 → 滴滴下山 → 高铁返程 |

> 节奏建议：莫干山的核心体验是"在山里慢"。**1 天 1 夜根本不够**（光路上就 3 小时），2 天 1 夜是底线，3 天 2 夜才能完整体验"清晨竹海 + 白天骑行 / 徒步 + 夜晚星空"。一天打卡式赶路毫无意义。

| 景点 | 为什么避 |
| --- | --- |

**避雷区域**：**莫干湖度假区**（在德清县城西边水库旁，硬贴莫干山牌子，跟山上完全无关）；**未在 OTA 露面的"农家乐"**（山上有大量挂"民宿"牌的家庭旅馆 ¥200 / 晚，硬件停留在 2010 年）。

## 打包清单

**必带**：身份证 + 微信 / 支付宝 + 充电器 + 一双能走山路的鞋（休闲徒步鞋或耐磨运动鞋，**别穿凉鞋 / 高跟**，山路碎石多）

**5-10 月特定**：
- **防蚊液 + 风油精**：山上蚊子大且毒，黄昏出门必喷；民宿都备但效果一般
- **薄长袖外套**：山顶昼夜温差 8-10°C，6 月晚上 18°C 也凉
- **防晒霜 SPF50+**：山上紫外线比城里强，竹海曝光时间长
- **充电宝**：徒步、骑行无电源；民宿一般有但白天出门一定带

**11-3 月特定**：
- **羽绒服 + 围巾 + 暖宝宝**：山顶 0-5°C，民宿外都需要保暖；部分民宿冬季关闭
- **防滑鞋底**：冬季山路偶有薄冰，碎冰扎实

**别带**：大行李箱（民宿小巷、台阶多，拉箱子很狼狈，建议 30 L 双肩包 + 软包）

> 真心话：山上中端以上民宿基本都准备了拖鞋 / 洗漱用品 / 浴巾，**牙刷牙膏**也都还会送（浙江 2024 起虽限制酒店免费六小件，但民宿仍可配）；行李带的越少，山道台阶越好走。

## 实用信息

- **24 h 便利店**：**只在山下莫干山镇有 1 家全家**（镇政府对面）；**山上完全没有便利店**；上山前在镇上 / 庾村买齐零食、瓶装水、电池
- **最近医院**：**德清县人民医院**（武康街道英溪南路 120 号，24 h 急诊，距离山顶约 30 km）；**莫干山镇卫生院** 处理小伤
- **信号盲区**：裸心谷内部、塔山西侧山涧、武陵竹海中段部分区域；移动信号最稳，电信次之，联通最弱
- **WiFi 应急**：庾村 1932 园区、民宿大堂、镇上咖啡馆都有
- **垃圾分类**：浙江全省执行，民宿房间内有四色桶；山道上没有垃圾桶，徒步带塑料袋自己装
- **山林防火**：5-10 月禁带明火上山（含烟头、香薰），违者罚款 200 起；想露营烧烤要选民宿院内或合规营地

> 真心话：**联通用户进山前先把民宿地址、餐厅、地图截图存好**，到了塔山以西的山涧确实有 200 米左右的连不上网区段；移动卡这点最稳。

## 避雷集合（我自己踩过的坑）

- **不要工作日订完民宿后周末加价改单** —— 同一家民宿周日改周六价格能涨 60%，且常常已无房；周末必去就一开始按周末价订
- **不要 8 月暑假高峰来** —— 民宿价格双倍 + 一房难求 + 山上山下都堵车 + 蚊子最毒；要避暑改 6 月初或 9 月底，温度差不多便宜一半
- **不要为景区门票 80 元单独腾半天** —— 老别墅 80% 不开放只能远观，剑池 30 分钟看完；如果民宿在景区外，进一次景区还要换乘车再加 ¥12，性价比极低
- **不要白天去武陵竹海** —— 9 点后旅游团一波波，竹林里全是人和喧哗，根本拍不出空镜；早 6:30 起床那 1.5 小时是唯一窗口
- **不要在山上吃农家"野味"** —— 不仅违法（野生动物保护法），且大概率是冷库假货；笋、土鸡、溪鱼这些合规家常才是真本地味
- **不要省高铁站到民宿的接驳** —— 一些便宜民宿不送站，自己滴滴上山 ¥120-150，看似省了 ¥150 接驳费但加了 1 小时麻烦；订之前问清楚"送不送站"
- **不要相信"山上租自行车骑行"的攻略** —— 山顶到山下海拔 700 m 落差，**新手骑下去就是要命**；想骑行去后坞乡平缓乡道，从民宿借踏板车更靠谱
- **不要带相机三脚架去莫干山风景区** —— 周末门口长枪短炮排队进，景区里游客挤到没空镜；想拍片就把器材留给清晨竹海和民宿露台

## 写在最后

> 莫干山最值得的不是任何一栋民国别墅、不是任何一片竹海，而是 **入住一家像样民宿的当晚 21:00 之后** —— 城里的电话信号已经弱了，露台外面除了虫鸣什么声音都没有，山上灯光稀疏所以银河肉眼可见。那一刻你才会明白为什么 100 年前的传教士们要花一整个夏天来这里、为什么蒋宋会反复回来、为什么"裸心谷"能在 2007 年从这里把中国民宿业从 0 启动。**杭州出发的周末，最值的不是去哪里，而是从城市断开 24 小时**。莫干山是江浙沪 3 小时圈内做这件事最熟练的地方。
