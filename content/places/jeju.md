## 一句话点评

- **适合谁**：想要海岛 + 火山 + 徒步一次拿下、喜欢自然多过都市的人；家庭亲子、情侣、徒步党、摄影党；想在韩国换个节奏的人

## 关于济州岛

**地理概况**：济州岛（제주도）在朝鲜半岛西南海面，是韩国最大的岛，整座岛由火山喷发形成，中央耸立着韩国最高峰**汉拿山（한라산，1,947 m）**，四周是玄武岩海岸、熔岩洞和大大小小 360 多座"오름"（寄生火山锥）。岛不大，租车 / 包车环一圈约 200 km、一天能绕完，但值得看的东西沿海岸线铺开，通常按 **东部（城山 / 牛岛）+ 西部（挟才 / 山房山）+ 汉拿山** 分区玩。

**行政与分区**：北边是**济州市（제주시）**（机场 + 市区 + 东门市场所在），南边是**西归浦市（서귀포시）**（瀑布 + 柱状节理 + 更暖），两座城由横穿汉拿山的 1131 号"5·16 道路"和平和路连接，开车翻岛约 1 小时。

**签证与免签**：济州岛长期对多数外国游客有**直飞免签停留 30 天**的特殊政策，中国团队游客历史上可免签落地；但个人游、K-ETA 电子许可的适用范围经常调整。**这是全岛最需要提前确认的一件事，出发前查最新官方口径，别按老攻略想当然。**

**最佳季节（概述）**：济州是韩国最温暖的地方，四季都能去，但画面完全不同——详见下一节 [四季怎么玩](#四季怎么玩)。一句话：**天气最舒服是 10-11 月，海水浴要 7-8 月，赌花期看 3-4 月，最暖又最静是 12-2 月。**

**抵达方式**：99% 走**济州国际机场（CJU）**，上海浦东 / 虹桥、杭州、北京等地有直飞，飞行 1.5-2h。机场离济州市区仅 20-30 min，落地即可开玩。

## 四季怎么玩

> 济州最好玩的地方：同一条海岸线，四季是四个不同的岛。下面按季节给「画面 + 去哪 + 注意什么」。

| 季节 | 月份 | 画面主题 | 推荐去处 | 关键提醒 |
| --- | --- | --- | --- | --- |
| **春** | 3 月中-5 月 | 油菜花金黄 + 樱花 + 新绿茶田 | 城山日出峰下油菜花田 / 涉地可支 / 녹산로鹿山路油菜+樱花 / 오설록茶园 | 樱花+油菜同框窗口只有 3 月底两周；海风仍凉 |
| **夏** | 6-8 月 | 翡翠海水浴 + 牛岛 + 瀑布 | 挟才 / 金宁海水浴场 / 牛岛 / 天地渊瀑布 / 汉拿山避暑 | 6 月底-7 月梅雨、8-9 月台风；防晒 + 防潮 + 关注台风 |
| **秋** | 9 月底-11 月 | **芒草银浪 + 汉拿山红叶 + 柑橘初熟** | 山君不离 / 따라비오름芒草 / 汉拿山灵室-御里牧红叶 / Olle 徒步 | **全年天气最佳**，晴空通透、风小，旺季但值得 |
| **冬** | 12-2 月 | 山茶花红 + 汉拿山雪白鹿潭 + 柑橘采摘 | 카멜리아힐山茶花园 / 汉拿山雪景登顶 / 柑橘园采摘 / 涯月海边咖啡 | 全国最暖但海风刺骨；登顶白鹿潭须冰爪 + 厚羽绒 |

**分季节的真心话：**

- **秋季（首选）**：10-11 月是济州一年里天空最干净、海最蓝、风最小的时候。**山君不离火山口的억새（芒草）** 10 月中下旬翻起银白色波浪，配蓝天封神；汉拿山灵室段红叶 10 月中到底。缺点是撞韩国秋游 + 中国国庆，房价涨、机票贵。
- **夏季（海岛正季）**：想下海就得这时候来，挟才海边的翡翠色只有夏天最浓，牛岛、海水浴场全开。但**6 月底到 7 月是梅雨、8-9 月是台风季**，务必买可退改机票、盯台风路径，被台风封岛 2-3 天不是稀奇事。
- **冬季（小众且暖）**：济州冬天 5-10℃，是韩国最暖的越冬地，山茶花从 11 月红到 2 月，柑橘正当季可下地采摘。**汉拿山冬天的雪 + 白鹿潭结冰** 是登山党的隐藏款，但要冰爪 + 全套防寒，海边风大体感更冷。
- **春季（赌花期）**：3 月底樱花和油菜花同时开的那两周是济州最出片的时刻，但花期每年浮动，要盯当地花讯；4 月油菜花仍大片，樱花已落。

## 行程建议（按天数选 · 岛是环形，分东西两半）

> 济州的玩法是"环形积木"：机场在北，景点沿海岸铺开，通常**东部一天、西部一天、汉拿山一天、市区 / 机动一天**。下面模块可单走也能拼接，默认济州市进出。

### 模块 A · 东部海岸线（1-2 天 · 日出与熔岩）

| 时段 | 地点 | 要点 |
| --- | --- | --- |
| 清晨 | 城山日出峰 | 火山口看海上日出，爬顶 25 min |
| 上午 | 涉地可支 | 海崖草坡 + 灯塔，《ALL IN》取景 |
| 中午 | 城山 / 终达里 | 海女海鲜 / 紫菜包饭午餐 |
| 下午 | 牛岛（旺季） | 环岛电瓶车 / 白沙滩，需坐渡轮 |
| 傍晚 | 万丈窟 / 山君不离 | 熔岩洞 或 火山口芒草（秋） |

> **路线说明**：东部是济州"日出 + 火山地貌"最集中的一段。城山日出峰要赶日出就得摸黑出发（查当日日出时间），爬到火山口边缘约 25 min。牛岛需在城山港坐渡轮 15 min，旺季 + 好天气才值得单独排半天；淡季或时间紧可舍。山君不离的芒草是秋季专属，其他季节可用万丈窟熔岩洞替代。

### 模块 B · 西部海岸线（1-2 天 · 翡翠海与茶田）

| 时段 | 地点 | 要点 |
| --- | --- | --- |
| 上午 | 오설록茶园 + innisfree | 绿茶田 + 抹茶甜品 |
| 中午 | 山房山 / 沙溪 | 山房窟寺 + 龙头海岸 |
| 下午 | 大浦柱状节理带 | 玄武岩六棱柱海崖 |
| 傍晚 | 挟才 / 涯月海边 | 翡翠海 + 海边咖啡看日落 |

> **路线说明**：西部主打"海 + 茶 + 咖啡"。오설록茶园（绿茶田 + 茶博物馆）和隔壁 innisfree 是西部起点，往南到山房山、龙头海岸看玄武岩海景，再到西归浦的大浦柱状节理带看六棱柱。收尾放在**挟才海边或涯月咖啡街**看日落——挟才的水色和远处飞扬岛是济州最"海岛"的一张画面。

### 模块 C · 汉拿山登顶（1 天 · 须提前预约）

| 路线 | 单程 | 往返用时 | 能否到顶 |
| --- | --- | --- | --- |
| 城板岳（성판악） | 9.6 km | 8-9h | 可到白鹿潭顶 |
| 观音寺（관음사） | 8.7 km | 9-10h | 可到顶，最陡最美 |
| 灵室（영실） | 5.8 km | 4-5h | 只到 1,700 m 展望台（红叶最佳） |
| 御里牧（어리목） | 6.8 km | 5-6h | 到 1,700 m 윗세오름 |

> **路线说明**：想登顶白鹿潭火山口只有 **城板岳 / 观音寺** 两条线，且**必须提前在国家公园官网预约当日名额**（免费限流，旺季秒光）。体力一般或只为看红叶，选**灵室线**——最短最美，秋天红叶在这一段。全程无补给，须自带水和干粮，务必查当天封山 / 天气公告。

### 模块 D · 市区 + 机动（0.5-1 天）

| 段落 | 内容 | 要点 |
| --- | --- | --- |
| 济州市 | 东门传统市场 + 黑猪肉一条街 | 夜市小吃 + 흑돼지烤肉 |
| 西归浦 | 每日偶来市场 + 正房 / 天地渊瀑布 | 更暖，瀑布市区可达 |
| 机动 | 泰迪熊博物馆 / 咖啡街 / Olle 徒步 | 看兴趣取舍 |

> **拼接建议**：4 天 = A + B + D；5-6 天 = A + B + C + D，把汉拿山单独占一天。**环岛方向固定一个（顺 / 逆时针）别来回折**，济州景点沿海岸，走回头路最浪费时间。

## 交通详解

> **先说最重要的一件事**：中国大陆驾照在韩国**不能**租车自驾。中国未加入《日内瓦 / 维也纳道路交通公约》，办不了韩国认可的国际驾照（IDP）。所以大陆游客的济州交通只有下面三条路，自驾那条是给港澳 / 海外 / 持有效 IDP 的人看的。

### 方式一：包车 / 拼车（大陆游客首选）

| 维度 | 说明 |
| --- | --- |
| 形式 | 中文司机拼车（拼满 4 人）或整车包车，按天计 |
| 价格 | 拼车 150-250 元 / 人 / 天；整车包车 800-1,200 元 / 天 |
| 怎么找 | 携程 / 韩游网 / 大众点评济州包车、或民宿代订 |
| 优点 | 不用操心停车 / 语言 / 路线，景点门口下车，能装行李 |
| 缺点 | 时间迁就同车人，摄影想多停需提前说 |

> **包车避坑**：① 确认报价含不含油 / 停车 / 司机餐；② 别贪"低价包车 + 带你去人参店 / 免税店"的购物团；③ 拼车提前问同车人数和行程是否兼容。

### 方式二：巴士 + T-money（最省，适合慢玩）

| 维度 | 说明 |
| --- | --- |
| 干线巴士 | 环岛急行 / 支线巴士覆盖主要景点，单程 1,150-3,000 KRW（¥6-16） |
| 市内公交 | 济州市 / 西归浦市内 1,150 KRW 起，刷 T-money |
| 优点 | 便宜，落地机场即可办 T-money |
| 缺点 | 班次疏、换乘久，去偏远오름 / 海边末端不方便，冬夏候车受天气影响大 |

> 真心话：巴士适合天数多、节奏慢、以市区 + 主景点为主的人。想一天扫多个分散景点，还是包车效率高一大截。

### 方式三：自驾（仅限持有效 IDP：港澳 / 海外 / 第三国驾照）

| 维度 | 说明 |
| --- | --- |
| 证件 | 需**日内瓦公约 IDP + 本国驾照原件 + 护照**（大陆驾照办不了 IDP） |
| 租车 | 机场周边租车行密集，小车 5-8 万 KRW / 天（¥260-420），旺季提前订 |
| 路况 | 岛内路况好、限速严（区间测速多），加油便利 |
| 优点 | 环岛 + 偏远海边 / 오름 自由度最高 |

> **自驾避坑（持 IDP 者）**：济州区间测速极严，务必守限速；海边停车场旺季爆满；冬季汉拿山盘山道 5·16 道路偶有结冰。

## 避雷集合（全局踩坑）

- **别指望用国内驾照自驾** — 大陆驾照办不了韩国认可的国际驾照，租车行不给车；老攻略里的"济州自驾"是给港澳 / 海外读者的，大陆游客用包车 / 巴士
- **签证 / 免签政策每年变** — 直飞免签、个人游资格、K-ETA 适用范围反复调整，**以出发前官方最新口径为准**，别照搬旧攻略
- **台风季（8-9 月）赌天气** — 封岛停航是常态，务必买可退改机票 + 留缓冲天，别把牛岛 / 出海排在最后一天
- **旺季房价机票翻倍** — 暑期 + 韩国连休 + 中国国庆，机票房价 ×1.5-2 且断货，非旺季不可去就提前 30-45 天订
- **"低价包车 / 一日游"绑购物** — 便宜团靠人参店 / 免税店返佣回本，认准"纯玩不进店"
- **汉拿山登顶没预约白跑** — 城板岳 / 观音寺线须官网提前抢当日名额，没码不让上；只看红叶走灵室线不必登顶
- **环岛来回折返最费时** — 景点沿海岸线状分布，定好顺 / 逆时针一个方向走，别东西来回横跳

## 写在最后

> 济州最打动我的是它的"两极"——同一天里，清晨能站在城山日出峰的火山口边看太阳从海里爬出来，午后能在挟才海边把脚泡进翡翠色的水里，傍晚还能在涯月的海边咖啡馆看日落。它不像首尔那样繁华，好玩的全是自然给的：火山、海、茶田、柑橘、海女。**先按季节定画面（秋天天气最好、夏天下海、冬天最暖最静），再定天数、最后挑东西线**——想清楚这三步，再加一句"我不能自驾、得安排好包车或巴士"，济州就能玩得很顺。
