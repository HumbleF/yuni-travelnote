## 关于成都

四川省省会，人口约 2,140 万，是中国西南最大的城市。成都因「天府之国」而得名，气候温润，物产丰富，自古"少不入蜀，老不出川"。盖碗茶、麻将、火锅、熊猫——这座城市最迷人的，恰恰是那种被现代生活速度挤压后愈发珍贵的"慢"。

| 项目 | 信息 |
| --- | --- |
| 货币 | 人民币 (CNY) |
| 气候 | 亚热带季风，年均 16℃；夏季湿热，冬季少阳 |
| 通讯 | 国内三大运营商 4G/5G 全覆盖 |
| 机场 | 双流国际 (CTU) + 天府国际 (TFU)，地铁直达市区 |
| 方言 | 成都话（西南官话），普通话普及度高 |

## 美食推荐

成都被联合国授予"世界美食之都"。这里的核心是 **辣椒 + 花椒 + 烟火气**，但其实甜口、咸鲜、清淡的菜也都做得极好。

| 类别 | 推荐店家 | 人均 |
| --- | --- | --- |
| 火锅 | 小龙坎、电台巷、大龙燚、蜀大侠 | 100-150 元 |
| 串串香 | 玉林串串香、马路边边、王梅串串 | 60-100 元 |
| 冒菜 | 盘飧市冒菜、三顾冒菜 | 30-50 元 |
| 川菜小馆 | 陈麻婆豆腐、明婷饭店、子非 | 80-200 元 |
| 小吃合辑 | 龙抄手（春熙路总店）、钟水饺、夫妻肺片、蛋烘糕 | 20-50 元 |
| 早茶 | 鹤鸣茶社（人民公园） | 10-20 元 / 杯，可坐一上午 |

> 不能吃辣：火锅点 **鸳鸯锅** 或要"微微辣"（本地"微辣"已经偏辣）；冒菜可换"藤椒清汤"。

## 实用小贴士

- **熊猫基地早起是关键**。10 点后熊猫基本回笼睡觉，活动时间集中在 7:30-9:30。
- **火锅的"九宫格"是有讲究的**：中间最辣，四角最温和，先放鸭肠、毛肚等"七上八下"涮 15 秒即可。
- **盖碗茶要慢慢喝**。10-20 元一杯无限续水，本地人能从早坐到晚，是体验市井生活最便宜的方式。
- **春熙路 / 太古里夜里人非常多**，怕挤可以下午 3-5 点去。
- **乘地铁通勤错峰**，早 8:00-9:30 / 晚 5:30-7:00 高峰段建议预留半小时缓冲。
- **夜啤酒一定要试**：傍晚街边支起小桌，10 元一扎冰啤 + 烤兔头/烤生蚝，是最成都的夏天。
