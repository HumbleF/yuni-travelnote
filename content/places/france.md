## 一句话点评

- **适合谁**：想一次玩到都市 + 田园 + 海岸 + 雪山的人；喜欢博物馆 / 美食 / 葡萄酒 / 摄影 / 自驾乡村的人；愿意按季节挑大区、不赶景点的慢玩派
- **不适合谁**：只有 4-5 天还想玩遍全法的（那就专心待巴黎）；受不了欧洲物价 / 罢工 / 大城市扒手的；夏天怕挤怕热又非要挤南部旺季的
- **最大亮点**：6 月中到 7 月中**普罗旺斯瓦朗索勒高原的薰衣草花海**，和 9-10 月**波尔多 / 勃艮第葡萄采收季的金色葡萄园**——一个是紫、一个是金，法国最好的两张画面都在城市之外

## 关于法国

**地理概况**：法国是西欧最大的国家，地形像一个六边形（法国人自称 l'Hexagone）：北部平原 + 大西洋 / 英吉利海峡海岸，中部丘陵与河谷，东部是阿尔卑斯和莱茵河，南部是地中海和比利牛斯山。首都巴黎在北部塞纳河畔，其余精华散在各大区——**这也是为什么法国要"按大区 + 按季节"玩，而不是一条线走到黑**。

**分区速记**：**巴黎 + 法兰西岛**（博物馆 + 凡尔赛）/ **普罗旺斯 - 蔚蓝海岸**（薰衣草 + 地中海，南部）/ **卢瓦尔河谷**（城堡群，巴黎西南）/ **阿尔萨斯**（德法交界，酒乡 + 圣诞集市，东部）/ **波尔多 - 勃艮第**（葡萄酒）/ **阿尔卑斯 - 萨瓦**（滑雪 + 勃朗峰，东部）/ **诺曼底 - 布列塔尼**（圣米歇尔山 + 登陆海滩，西北）。

**签证**：中国公民需申根签证，材料齐全一般 15 个工作日内出签，一张签证可在整个申根区通行，**从法国进出是常见方案**。

**最佳季节（概述）**：法国四季都能玩，但画面和大区完全不同——详见下一节 [四季怎么玩](#四季怎么玩)。一句话：**看薰衣草只有 6 月中-7 月中，天气最舒服人最少是 9-10 月，滑雪 + 圣诞集市在 12 月-2 月，巴黎本身春秋最好。**

**抵达方式**：99% 从**巴黎戴高乐机场（CDG）**进出，上海 / 北京有直飞（约 12-13h）；机场靠 RER B 线或机场大巴进城约 45 min。之后城际靠 TGV，乡村大区（普罗旺斯 / 卢瓦尔 / 阿尔萨斯）再租车自驾。

## 四季怎么玩

> 法国最特别的地方：同一个国家，四季是四组完全不同的大区。下面按季节给「画面 + 去哪 + 注意什么」。

| 季节 | 月份 | 画面主题 | 推荐大区 | 关键提醒 |
| --- | --- | --- | --- | --- |
| **春** | 3-5 月 | 巴黎花园返青、卢瓦尔城堡、莫奈花园 | 巴黎 / 凡尔赛 / 卢瓦尔河谷 / 吉维尼 | 天气多变常带雨；复活节 + 五一假期人多价升 |
| **夏** | 6-8 月 | **薰衣草花海** + 蔚蓝海岸 + 超长日照 | 普罗旺斯（薰衣草 6 月中-7 月中）/ 尼斯戛纳 / 科西嘉 | 旺季最贵最挤，南部酷热，8 月部分小店 / 餐厅歇业度假 |
| **秋** | 9-11 月 | **葡萄采收金秋** + 阿尔萨斯酒乡 + 巴黎金色 | 波尔多 / 勃艮第 / 阿尔萨斯 / 巴黎 | **全年最舒服、人少价降**，最被低估的季节 |
| **冬** | 12-2 月 | 阿尔卑斯滑雪 + 圣诞集市 + 巴黎灯饰 | 霞慕尼 / 各滑雪场 / 斯特拉斯堡 + 科尔马 / 巴黎 | 北部阴冷日照短；滑雪 + 圣诞旺季贵，圣诞前两周最挤 |

**分季节的真心话：**

- **秋季（最舒服、最值）**：9-10 月天气凉爽稳定、游客散去、住宿降价，还能赶上波尔多 / 勃艮第的葡萄采收（vendanges）和阿尔萨斯酒乡的金色葡萄园。想第一次去法国又怕挤怕贵，**秋天是最优解**。
- **夏季（薰衣草专属）**：想看薰衣草只能这时候来，**瓦朗索勒高原 6 月中开到 7 月中、塞南克修道院前的花田是经典机位**；但南部 7-8 月又热又挤、价格翻倍，且 8 月很多本地小店关门度假，行程前查营业。
- **冬季（滑雪 + 圣诞）**：阿尔卑斯（霞慕尼 / Val d'Isère / Courchevel）是欧洲顶级雪场，12-4 月雪季；**阿尔萨斯的斯特拉斯堡 + 科尔马圣诞集市是全法最有名的**，11 月底开到圣诞。缺点是巴黎冬天阴冷、下午 5 点天黑。
- **春季（巴黎 + 城堡）**：巴黎的公园、凡尔赛花园、卢瓦尔城堡、吉维尼的莫奈花园在 4-5 月最美，但天气忽晴忽雨，一定带伞和外套。

## 行程建议（按大区选 · 看季节和天数拼模块）

> 法国的玩法是"大区积木"：先选一个季节主线，再按天数拼大区。所有模块默认**巴黎 CDG 进出**，城际用 TGV，乡村段落自驾。

### 模块 A · 巴黎核心（3-4 天 · 全年）

| Day | 路线 | 要点 |
| --- | --- | --- |
| 1 | 卢浮宫 + 杜乐丽 + 塞纳河 | 卢浮宫需提前订，半天足够 |
| 2 | 埃菲尔铁塔 + 战神广场 + 塞纳河游船 | 铁塔上午光好，夜里整点闪灯 |
| 3 | 凡尔赛宫（一日） | 提前订，宫殿 + 花园 + 特里亚农 |
| 4 | 蒙马特 + 圣心堂 + 奥赛 | 奥赛看印象派，蒙马特防扒手 |

> **路线说明**：巴黎公共交通发达，全程地铁 + 步行，别自驾。卢浮宫、凡尔赛、埃菲尔都要**官网提前订时段票**，现场排队动辄 1h+。凡尔赛单独占一天（RER C 直达约 40 min），花园旺季周末有喷泉音乐秀另收费。

### 模块 B · 普罗旺斯 + 蔚蓝海岸（4-6 天 · 夏首选）

| Day | 路线 | 要点 |
| --- | --- | --- |
| 1 | 巴黎 TGV → 阿维尼翁，租车 | 教皇宫 + 断桥 |
| 2 | 瓦朗索勒薰衣草 + 塞南克修道院 | 6 月中-7 月中花期，日出 / 日落光最好 |
| 3 | 石头城 Gordes + 红土城 Roussillon | 吕贝隆山区小镇 |
| 4 | 还车 → 尼斯 | 天使湾 + 老城 + 城堡山 |
| 5 | 埃兹小镇 + 摩纳哥 | 山城海景 + 蒙特卡洛 |

> **路线说明**：普罗旺斯的薰衣草和山区小镇分散、公交差，**必须自驾**（阿维尼翁 / 艾克斯取车）。蔚蓝海岸段（尼斯 / 摩纳哥）城市间火车方便，可还车改火车。薰衣草只在**6 月中到 7 月中**，早了没开、晚了收割，务必卡花期；正午顶光发白，赶日出日落。

### 模块 C · 卢瓦尔城堡（1-2 天 · 春夏秋）

| 段落 | 内容 | 要点 |
| --- | --- | --- |
| 城堡群 | 香波堡 Chambord + 舍农索 Chenonceau | 两座最经典，一天可看 2-3 座 |
| 基地 | 图尔 Tours / 布卢瓦 Blois | 巴黎 TGV 1h 到，自驾串城堡 |

> **路线说明**：卢瓦尔城堡群分散在乡间，巴黎坐 TGV 到图尔 / 布卢瓦后租车或参加当地一日游最顺。香波堡（弗朗索瓦一世 + 达芬奇双螺旋楼梯）和舍农索（横跨谢尔河的"贵妇城堡"）是必看的两座，别贪多，一天 2-3 座刚好。

### 模块 D · 阿尔萨斯（2-3 天 · 秋 / 圣诞）

| 段落 | 内容 | 要点 |
| --- | --- | --- |
| 斯特拉斯堡 | 大教堂 + 小法兰西 + 圣诞集市 | 全法最有名的圣诞市集 |
| 科尔马 + 酒乡小镇 | 科尔马 + 里克维尔 + 埃吉桑 | 半木屋童话镇 + 白葡萄酒 |

> **路线说明**：巴黎 TGV 到斯特拉斯堡约 1h50，再租车或坐区域火车 + 巴士串科尔马和酒乡小镇。**秋天是金色葡萄园 + 半木屋，11 月底到圣诞是灯火通明的圣诞集市**，两个季节都很好，避开圣诞前最后两周的人潮。

### 模块 E · 阿尔卑斯（2-4 天 · 冬滑雪 / 夏徒步）

| 段落 | 内容 | 要点 |
| --- | --- | --- |
| 霞慕尼 Chamonix | 南针峰缆车看勃朗峰 + 滑雪 | 冬雪场 / 夏徒步两季都行 |
| 大雪场 | Val d'Isère / Courchevel / Tignes | 12-4 月雪季，需提前订雪票住宿 |

> **路线说明**：滑雪或看勃朗峰从霞慕尼进最方便（日内瓦机场转大巴更近，也可巴黎 TGV 到安纳西 / 圣热尔韦转）。**冬季雪季 12-4 月、雪票 + 雪具 + 住宿旺季很贵要提前订**；夏季来则是徒步 + 南针峰缆车看勃朗峰。

> **拼接建议**：首刷 7-8 天 = A（巴黎）+ 一个大区（夏选 B 薰衣草 / 秋选 D 阿尔萨斯 / 冬选 E 滑雪）；10-12 天可 A + 两个大区。**别想一趟玩遍全法**——法国精华在"选对季节深玩一两个大区"，不是打卡。

## 真实预算（2 人 8 天 · 巴黎 + 普罗旺斯 · 夏季 · 上海出发）

| 项目 | 金额 (人民币) | 备注 |
| --- | --- | --- |
| 往返机票 | 6,500 × 2 = 13,000 | 上海 ↔ 巴黎 CDG 直飞，夏季旺季，提前 60 天 |
| 申根签证 | 700 × 2 = 1,400 | 签证费 + 服务费 + 材料 |
| TGV（巴黎 ↔ 阿维尼翁往返） | 600 × 2 = 1,200 | 提前买 Prem's 折扣票能更低 |
| 普罗旺斯租车（3 天） | 1,500 | 含油 + 高速 + 保险，2 人分摊 |
| 住宿（7 晚 · 巴黎中端 + 普罗旺斯民宿） | 1,300 × 7 = 9,100 | 巴黎 ¥1,200-1,800 / 普罗旺斯民宿 ¥800-1,200 |
| 餐食（8 天 × 2 人） | 400 × 8 = 3,200 | 含 1-2 顿正经法餐 + 面包甜点日常 |
| 门票 / 缆车 / 游船 | 250 × 2 = 500 | 卢浮宫 / 凡尔赛 / 埃菲尔 / 教皇宫等 |
| 备用 / 手信 | 600 × 2 = 1,200 | 突发 + 葡萄酒 + 化妆品 |
| **合计** | **约 31,100** | **人均 ≈ 15,550 元**；秋季错峰机票住宿可降 20-30% |

> 真心话：法国预算的三大头是**机票 + 住宿 + 城际交通**，门票反而不贵（很多博物馆几十欧）。省钱关键：① 机票住宿避开 7-8 月和圣诞；② TGV 提前 2-3 个月买 Prem's 折扣票，早买能省一半；③ 一顿米其林能顶三天日常，量力而行。

## 交通详解

### 大交通（进出 + 城际）

| 场景 | 方式 | 参考价 | 用时 |
| --- | --- | --- | --- |
| 上海 / 北京 ↔ 巴黎 CDG | 直飞 | ¥5,000-9,000 往返 | 12-13h |
| CDG 机场 ↔ 巴黎市区 | RER B / 机场大巴 / 出租 | €11.8 / €16 / €56 定价 | 35-60 min |
| 巴黎 ↔ 各大区 | TGV 高铁 | 提前买 €25-70 | 1h50-6h |
| 城际备选 | 国内航班 / FlixBus 巴士 | 巴士最便宜 | 视距离 |

> **TGV 攻略**：用 **SNCF Connect** App / 官网订票，**提前 2-3 个月放 Prem's 特价**，越早越便宜且不可退改；临买贵一倍。高铁站按票面车厢号站台候车，进站不安检但要打卡（电子票扫码）。

### 市内 + 乡村

| 方式 | 说明 |
| --- | --- |
| 巴黎地铁 / RER | 覆盖全城 + 凡尔赛，买 Navigo Easy 卡或单程票，**看紧随身物品** |
| 乡村自驾 | 普罗旺斯 / 卢瓦尔 / 阿尔萨斯必备；中国驾照 + 法语公证翻译件，出发前与租车行确认 |
| 区域火车 TER + 巴士 | 蔚蓝海岸 / 阿尔萨斯城镇间可用，班次比自驾疏 |
| 出租 / Uber | 巴黎 Uber 普及，乡村靠预约 |

> **自驾避坑**：法国乡村路况好但限速严（区间测速 + 测速拍照多），高速有收费站（备信用卡）；城市老城区禁行 / 难停车，**城市还车、乡村再取车**最省心；加油多为自助，认准 Gazole（柴油）/ SP95-98（汽油）别加错。

## 出片机位（按出片难度由易到难）

1. **夏乐宫（Trocadéro）看埃菲尔铁塔** — 6 号线 Trocadéro 站出，**清晨 7-8 点无人 + 逆光 / 傍晚整点闪灯**，广场正对铁塔中轴
2. **科尔马"小威尼斯"运河** — 半木屋 + 倒影，**上午顺光 / 圣诞夜灯火**，桥上竖构图
3. **普罗旺斯塞南克修道院薰衣草** — 修道院前花田，**6 月下旬-7 月上旬日出**，紫色花田 + 石修道院
4. **舍农索城堡横跨谢尔河** — 河对岸步道，**上午顺光 / 秋色**，城堡拱廊倒映水面
5. **埃兹小镇俯瞰蔚蓝海岸** — 鹫巢村最高处，**晴天上午**，山城 + 地中海蓝
6. **霞慕尼南针峰看勃朗峰** — 缆车登顶 3,842 m，**晴天上午通透**，注意高海拔 + 保暖

**全年必带**：护照（申根签 + 行程 / 保险打印备用）+ Visa / Master 信用卡（闪付常用）+ 少量欧元现金 + **欧标转换头（C / E 型，230V）**+ 防扒防盗（贴身斜挎包 / 防盗拉链，巴黎地铁 + 景点必备）

**春（3-5 月）**：风衣 + 薄毛衣 + 折叠伞（天气多变）+ 舒适步行鞋

**夏（6-8 月）**：透气衣物 + 防晒（南部日照强）+ 墨镜 + 泳衣（蔚蓝海岸）+ 薄外套（早晚 / 空调）

**秋（9-11 月）**：外套 + 针织 + 好走的鞋（酒庄 / 城堡多步行）+ 折伞

**冬（12-2 月）**：厚羽绒 + 围巾手套帽（北部阴冷）；**滑雪另备**：雪服 / 雪镜 / 防水手套 / 高倍防晒（雪地反光）

## 实用信息

- **治安 / 防扒**：巴黎地铁、铁塔 / 卢浮宫 / 圣心堂周边扒手团伙多，背包前背、别露手机钱包、警惕"请你签名 / 捡到戒指"搭讪
- **罢工（grève）**：法国铁路 / 地铁 / 航空罢工较常见，出发前查 SNCF / RATP 公告，重要行程留缓冲
- **营业时间**：多数商店周日 + 部分周一休息，午休（12:30-14:00）小店可能关门；8 月不少小店 / 餐厅整月度假
- **医疗 / 应急**：报警 17 / 急救 15 / 欧洲通用 112；中国驻法国大使馆 +33-1-8621-4488
- **网络**：eSIM（Orange / Airalo 欧洲多国通用）或到欧洲开通漫游；酒店 WiFi 普遍
- **小费**：餐费已含服务费，无需硬性小费，满意留 5% 或零头即可

## 避雷集合（全局踩坑）

- **别妄想一趟玩遍全法** — 法国精华散在各大区，一趟深玩巴黎 + 1-2 个大区，比每天赶火车打卡强得多；**先按季节选大区，再定天数**
- **薰衣草只在 6 月中-7 月中** — 早了没开、晚了收割，专程看薰衣草务必卡花期 + 查当年花讯，别按老照片想当然
- **提防扒手和街头骗局** — 巴黎地铁 + 热门景点扒手团伙、签名 / 手环 / 三张牌赌局，贴身防盗 + 不搭话
- **罢工可能打乱火车 / 航班** — SNCF / 航空罢工常见，出发前查公告，别把返程 TGV 和国际航班卡太死
- **旺季物价翻倍且难订** — 夏季南部 + 冬季雪场 + 圣诞集市房价机票双涨，非旺季不可去就提前 1-2 个月订
- **8 月很多小店关门度假** — 法国人自己放暑假，8 月部分餐厅 / 小店整月歇业，行程前查营业时间
- **退税 + 安检要留足机场时间** — 旺季退税 Pablo 机 + 安检排长队，别卡点到机场

## 写在最后

> 法国最难忘的从来不是某个非去不可的景点，而是"季节和大区对上了"的那一刻——7 月初站在瓦朗索勒的薰衣草田里被紫色和蜜蜂包围，10 月在勃艮第踩着落叶穿过金黄的葡萄园，12 月在科尔马的圣诞集市捧着热红酒看半木屋亮灯。它不适合赶行程，物价也不低，还得防着扒手和罢工。但只要你愿意**按季节挑一两个大区慢慢待**，再买上面包奶酪红酒去河边坐一下午，法国会用一个国家的四季，还你远超机票钱的东西。**先选季节，再定天数，最后才挑大区——这是玩透法国的正确顺序。**
